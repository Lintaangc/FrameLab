About Project

FrameLab is the final project for the Digital Image Processing course: a web application whose results come from real algorithms, not from visual effects.

How it works

Browser

HTML, CSS and vanilla JavaScript handle upload, playback, the camera (MediaDevices API) and the histogram charts (Chart.js). The browser never computes a result itself.

Flask API

Files and frames arrive over fetch() as multipart form data or JSON. Routes only validate input and delegate to services.

Python algorithms

Each method lives in its own module inside algorithms/ and uses OpenCV and NumPy. Images are kept in BGR order internally and converted from RGB exactly once, when they are decoded.

Video processing, stated plainly

The browser plays the video and, for every displayed frame, captures it to a canvas and posts it to /api/process-video-frame. The Python backend processes that frame with the selected algorithm and returns it, and the page draws it next to the original together with both histograms.

This is near real-time, not true real-time streaming. Round-trip time depends on your computer and frame size. In Near real-time mode the original keeps playing and frames the server could not process in time are skipped (the “Skipped” counter and “Result lag” show this). In Frame-locked mode the page seeks to each frame in order and waits for its result, so both videos always show the same instant, but playback is slower than real time.

API endpoints

MethodEndpointPurpose
GET/api/methodsMethod catalogue and parameter schema (builds the controls)
POST/api/upload-imageValidate and store an uploaded image
POST/api/process-imageRun a method on a stored image
GET/api/histogramHistogram of the original or the result (?id=…&which=original|result)
GET/api/download-resultDownload the latest result as PNG
POST/api/upload-videoValidate a video with OpenCV and read its metadata
POST/api/process-video-frameProcess one video frame (optionally return it as a PNG download)
POST/api/capture-processStore and process a webcam photo
